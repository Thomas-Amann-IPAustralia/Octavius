# Octavius
Octavius helps you audit, generate, and reshape APS content — from pasted text and .docx files to AI-authored material — with rule-driven feedback and structured data superpowers.

###GitHub repo -> Streamlit Community Cloud
  https://0ctavius.streamlit.app/

###The "No-Install" Development Loop
Since I can't run code on my machine, the workflow looks like this:

1. Edit on GitHub: You open your code file directly on GitHub.com and use their built-in web editor (press the . key on your keyboard while looking at a repository to open a "lite" version of VS Code in your browser).

2. Commit: You save your changes.

3. Auto-Deploy: Streamlit Community Cloud "sees" that you saved new code on GitHub and automatically restarts your app with the new changes.

4. View: You refresh your app's URL to see the results.
